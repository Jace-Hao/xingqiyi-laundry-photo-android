# 移动端 v1.1.0 发布说明

**一句话**：手机 App 现在能自己发现新版本、在手机上直接下载安装了 —— 不用再找电脑拷 APK。

| 项目 | 值 |
|---|---|
| 版本 | v1.1.0（内部编号 10501） |
| 适用系统 | Android 8.0 及以上 |
| **必须搭配** | 桌面端 **v1.2.4 或更高** |

---

## 一、店员现在能干什么

| 场景 | 以前 | 现在 |
|---|---|---|
| 有新版本 | 不知道，得等老板说 | 打开 App 会自己检查，发现新版本就弹窗告诉你 |
| 更新 | 找电脑 → 拷 APK → 传手机 → 允许未知来源 → 安装 | 在手机上点「立即更新」，看着进度，装完自动打开新版 |
| 正在接待客人 | — | 点「稍后再说」，先干活，下次打开 App 再提醒 |
| 不想装某一版 | — | 点「跳过此版本」，这版不再打扰（出了更新的版本才会再提醒） |
| 管理员要求必须更新 | — | 弹窗标题写明「管理员要求必须更新后才能继续使用」，并告诉你还剩几次可推迟 |
| 被强制更新拦住、暂时装不上 | — | 点「退出应用」先收工，回头再打开 App 继续 |

更新弹窗里会显示管理员写的更新说明、看不懂可以直接跳过。**跳过只在你主动点「跳过此版本」时生效**——在弹窗外面随手点一下不会跳过，不会有误触的烦恼。

### 离线照片不会丢

**这是我们最在意的一点，请放心更新。**

- 直接覆盖安装，App 里所有东西都保留：**没上传的离线照片、已建档记录、服务器地址、登录账号，一个都不会少**。
- 万一手机里还有照片没传到服务器，更新前会先弹窗告诉你「还有 N 张照片没上传」，你可以选：
  - **先传给服务器**（推荐，传完再更新）；
  - 或者直接继续更新，照片留在本地也不会丢。
- **唯一会丢照片的情况：手动卸载再重装。** 如果手机提示装不上、让你先卸载，**请一定不要卸载**，拍照联系技术支持。

## 二、管理员需要做什么

**把手机安装包放进桌面的「软件更新」文件夹，就够了。**

1. 拿到本次的 `xingqiyi-laundry-photo-android-v1.1.0-release.apk`；
2. 放进桌面端数据目录下的 `updates` 文件夹（即桌面端界面里「软件更新」对应那个目录）；
3. **建议**：在同一文件夹里放一个**同名**的 `.md` 文本文件（文件名把 `.apk` 换成 `.md`），内容随便写几句本次更新了什么。手机端更新弹窗会把它显示出来，店员看得懂就不会瞎点。
   - 没放也不影响更新，只是弹窗里会显示「管理员没有写这次的更新说明」。
4. **想让所有手机必须更新**（版本收口）：在桌面端「系统设置 → 强制更新」里勾选这个 APK。手机端下次打开就会进入必须更新的流程。

> 文件名里**必须带版本号**（如 `...-1.1.0.apk`），手机端认这个数字判断新旧，认不出来的文件会被忽略。
> 放 `.apk` 不会影响电脑自己更新，两种安装包可以放在一起。

## 三、已知限制（请一定读完）

这一节是我们主动交代的，不是敷衍。

### 1. 手机更新功能依赖桌面端 v1.2.4

手机上这套更新能力，是桌面端 v1.2.4 新增的接口提供的。**桌面端没升到 v1.2.4，手机端会「检测不到任何更新」** —— 不报错、不提示、就是没反应，等于更新功能是关着的。

**怎么办**：先把桌面端升到 v1.2.4 或更高，再让店员点更新。
**怎么确认有没有升**：在手机「设置 → 软件更新」里手动点一次「检查更新」，如果提示「这台服务器的桌面端版本较旧」，就是桌面端还没升。

### 2. 不会在后台偷偷下载

发现新版本**只弹窗，不自动下载**。必须店员本人在手机上点「立即更新」才开始下载。

这是有意为之：一家店几十台手机一起自动下载，会把店里的 WiFi 打满，手机流量也扛不住。

下载过程中可以切到别的页面继续干活，但**下载完不会自动装** —— 需要回来点安装。

进度有两种看法：**App 内的进度面板一定会显示**；如果手机允许了通知权限，Android 13 及以上还会在手机顶部下拉栏里显示下载进度。**Android 13 及以上第一次点下载时会问你要不要给通知权限，允许或拒绝都不影响更新** —— 拒绝了就看 App 内的进度面板，一样能下完能装好。

### 3. 强制更新有 24 小时 / 3 次的宽限期

管理员勾了强制更新之后，不是立刻锁死店员：

- 头 **24 小时**内、或店员**推迟 3 次**以内（谁先到算谁），都还能点「稍后再说」，App 每次打开会再提醒一次；
- **超过之后**才会强制拦截：这时候店员**没法跳过更新**，但有两个按钮可选 ——「立即更新」装上新版，或者点「**退出应用**」先收工。点「退出应用」会再问一次「确定要退出吗？」（提示：退出后仍需重新打开本应用才能继续拍照），确认后回到手机桌面，不会丢任何照片；下次打开 App 会接着提醒，直到更新完成。
  - 这一层二次确认是故意加的：强制拦截每次开 App 都会弹，店员误触一下就被「弹回桌面」的话，看起来就像 App 自己闪退了。多点一次，比误报故障省事。

这是为了不让店员正在接待客人时被硬拦。宽限期是固定的，暂不支持按门店自定义。

### 4. 手机要开「允许安装未知应用」

手机系统默认不允许装不是应用商店来的软件，第一次更新会引导你跳到系统设置里开这个权限。**界面上会有中文说明和「去设置」按钮，照着点就行，不用怕。**

- 国产手机（小米 / 华为 / OPPO / vivo 等）这个开关藏得比较深，位置每个牌子不一样。找不到就用手里的手机搜一下「允许安装未知应用」。
- 万一还是找不到，弹窗里还有「我已允许，继续安装」可以直接继续。

### 5. 首次下载中断要从头再来

下载是整包下载的，**没有断点续传**。中途断网或手机被杀掉，重新点下载会从头开始（门店 WiFi 下大约几十秒到几分钟）。

不过断网后 App 会自己重试 3 次，一般你不用管。网速特别慢（低于约 20KB/s）时也会停下来让你重试。

### 6. 桌面的强制更新下拉里会多出手机包条目

桌面端「系统设置 → 强制更新」的文件下拉框现在也会列出 `.apk` 文件（这是必须的，否则管理员没法勾手机包）。它没有加「（安卓包）」标签，**请留意别把 `.apk` 误当成电脑安装包勾错了**。

### 7. 桌面端版本号建议保持高于手机端

桌面端自己的更新检查早就会跳过更新目录里的手机安装包，所以**即使手机端版本号将来涨过桌面端，电脑也不会再把手机包装当成自己的更新推给电脑用户**——这一点由程序保证，不需要人工盯着。

即便如此，仍**建议**让桌面端版本号保持在手机端之上：一眼能看清两边谁新，也避免别的理解偏差。**违反了也不会造成误推送。**

## 四、怎么升级

### 手机端（v1.1.0）

- 装 **正式包**：`xingqiyi-laundry-photo-android-v1.1.0-release.apk`
- 已装 v1.0.0 的手机**直接覆盖安装**即可，不需要卸载，照片和配置都保留。
- 安装包 SHA-256 校验值见发布附件 `SHA256SUMS.txt`。

> **调试包（debug）注意**：调试包和正式包可以同时装在一部手机上（包名不同），但**如果你之前一直用的是调试包，换正式包必须先卸载调试包** —— 两者签名不同，不能覆盖。卸载前请确认离线照片都已上传。

### 桌面端（v1.2.4）

- 先把桌面端升到 **v1.2.4**，否则手机端的更新功能是关着的。
- 已装 v1.2.3 可直接覆盖升级，配置与数据不丢失。
